# Pong+
<img width="315" align="right" alt="Cover Art" src="https://github.com/user-attachments/assets/d7edb5a9-0138-40a5-92a0-dbd2dac38646" />

Play it here!: https://mydimons.itch.io/pong

Pong+ is a small project recreating the classic *[pong](https://en.wikipedia.org/wiki/Pong)* but with upgrades! 

This game was made as a project for a school class. 
The the assignemnt theme was 'pong' with a twist. 
The twist I added was **upgrades!**

This project was also mainly a testing ground to learn some things about [Unity](https://unity.com/products/unity-engine) and game development. 
I definitely learned a bunch about unity from this project and had a ton of fun making it!
